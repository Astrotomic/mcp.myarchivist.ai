# What Archivist makes

Only promise what the user's source can produce. If you show an example that their first session can't make, they'll be disappointed when it doesn't appear.

Legend for **Needs**:
- **notes** — any processed session, including one made from notes
- **transcript** — a transcript, audio or Discord voice session; not raw notes
- **record** — a single compendium record; no session needed

- **portrait** — a character record with an image; owner only, and the campaign must have AI images turned on

All examples are under `https://assets.myarchivist.ai/onboarding/artifacts/`.

## How to use this file

- Show **one or two** examples at the end (Step 5), chosen to match what they just made. Don't show all of them. Good pairings:
  - **After a notes session:** the hero award or key moment, plus the handout.
  - **After a transcript session:** the quote.
  - **After creating a character:** the trading card. Also the sprite, but only if the character has a portrait. Characters created in chat usually don't have one yet, so call the sprite something they can make once they add art.
- Where the Example column shows "—", there's no published example. Describe the artifact in a sentence instead.
- Images (`.png`, `.gif`): use markdown image syntax, `![Example hero award](url)`, so hosts that render images inline show them. Add a plain link after the image as a fallback for hosts that don't, e.g. `[See an example hero award](url)`.
- The handout is a PDF. Always post it as a link, never as an image.
- These are examples from a demo campaign, not the user's own content. Say so, e.g. "Here's one from our demo campaign".
- For a notes-based first session, mention once that recording or uploading a transcript next time unlocks quotes and cast analysis. Say it as information, not as a sales pitch.
